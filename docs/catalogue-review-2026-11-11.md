## Notable exclusions or caveats

- Excluded the Borivali 'Mumbai Ultra Marathon' whose directory date conflicts with the primary registration page.
- Excluded Yap & Run Women Only Run from the import because a stable, event-specific registration URL could not be independently verified; a generic sports directory is not an acceptable registration link.
- Founders Running Club events use direct date-specific Meetup pages and are free to attend according to public event listings; confirm RSVP requirements.
- Uhtend 5v5 football is listed at no extra entry fee, but **Luma registration requires host approval** and subscribers receive priority. The listing must never imply guaranteed access without approval or paid subscription.
- Child-focused events require parents/guardians to handle registration. Do not imply a minor may create a Mercury account.
- Free sessions on third-party providers are **external listings**, not free Mercury-native bookings or automatically confirmed places. The 'Free' Explore filter now includes exact 'Free' external listings.
- For Padel, some marketing pages advertise prize pools, **not ticket fees**. The catalogue uses 'See organizer' if an entry fee was not published.
- Where fee, registration deadline or precise venue could not be verified, the record says so instead of inventing a value.
- Venue and dates need an event-level recheck, especially for walking events where URL names may mention another date/year.
- Some source pages are intermediaries linking to third-party booking providers. When accessible, use the organizer's exact checkout; never link to an unrelated landing page.
- Listings become 'Needs source check' after 7 days under the site's existing freshness rule. A large catalogue requires an ongoing weekly review workflow.
- The expanded Pexels fallbacks remain *illustrative*, never photographs of these exact tournaments.
